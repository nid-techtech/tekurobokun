# tekurobokun（テクロボくん）

TECH☆TECHのマスコット「テクロボくん」と、声やキーボードで話せる展示用のロボットです。来場者がタブレットに話しかけると、テクロボくんが人格を持って返事をします。返事は、声・表情・口の動き・字幕で表します。

## 特徴

- **話しかけるだけ**：タブレットのキーボードのマイクを押して話すと、入力が止まって3秒後に自動で送られます。手で打っても使えます
- **声・表情・字幕で返事する**：返事の気分（うれしい・おどろき・困った など）に合わせて目の形が変わり、声に合わせて口が動きます。話している内容は、画面の左上に字幕で出ます
- **インターネットなしで動く**：AIの返事も音声も、会場のLANの中のPCで作ります。会話の内容は外に出ません
- **止まらずに動き続ける**：どの機器が再起動しても、つながり直せば自動で元に戻ります。つながらない間は、眠った顔になります
- **スタッフが手伝える**：混雑時や声が通らないときは、スタッフが手持ちのスマホから代わりに入力できます

## 入手方法

一般公開はしていません。展示に使うPCごとに、このリポジトリから準備して起動します。準備の手順は[CONTRIBUTING.md](CONTRIBUTING.md)にあります。

## 動作環境

展示は、次の3台を、持ち込みのルーターのLAN（インターネット接続は要りません）でつないで行います。

| 役割                                       | 環境                                                                          |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| 機体（顔を映して声を出すPC）               | Windows。ディスプレイとスピーカーをつなぐ                                     |
| バックエンドPC（返事を考えて、声を作るPC） | Windows 11。メモリ32GB、AMD Radeon RX 480で動作を確認                         |
| 入力端末（来場者が話しかける端末）         | Android端末のEdge（Lenovo Xiaoxin Padで確認）。キーボードはMicrosoft SwiftKey |

## 使い方

**来場者**

1. タブレットの画面の下にあるキーボードのマイクを押して、テクロボくんに話しかけます（手で打ってもかまいません）
2. 話し終えて3秒たつと、自動で送られます。すぐ送りたいときは「送る」を押します
3. テクロボくんが考えている間は入力できません。返事が終わると、また話しかけられます

**スタッフ**

- 手持ちのスマホからは、ブラウザで入力ページを`?device=phone`付きで開いて入力します。入力を受け付けるのは、いつでも1台だけです
- 入力する端末の切り替えは、バックエンドPCのキー操作で行います。手順は[CONTRIBUTING.md](CONTRIBUTING.md)の「展示当日の運用」にあります

## 注意事項

- **会話を記録しています**：来場者の発言とテクロボくんの返事は、バックエンドPCに保存されます。保存は最大3か月で、テクロボくんの学習に使うことがあります。学習に使う前に、個人が特定される情報は手で取り除きます。名前や連絡先など、知られたくないことは話さないでください
- **外部には送りません**：会話の内容は、LAN内のPCだけで処理し、インターネットのサービスには送りません
- **返事はAIが作っています**：事実と違うことや、的外れな返事をすることがあります。不適切な言葉は、禁止語のリストで検査し、当たったときは定型の返事に差し替えます。すべては防げません
- **機体の声を拾うことがあります**：タブレットのマイクが機体の声を拾って、来場者の発言として入力されることがあります。タブレットと機体の距離や向きを調整してください
- **コード署名がありません**：機体アプリ（Windows用の実行ファイル）にはコード署名がないため、初めて起動するときに、Windowsが「Windows によって PC が保護されました」と警告することがあります。出どころを確かめたうえで、「詳細情報」を押し、「実行」を選んでください
- **音声**：VOICEVOX 琴詠ニア
