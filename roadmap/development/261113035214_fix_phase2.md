# Phase 2 修正記録

## 261113035214 W2-1：Biomeが人格プロンプトの整形で失敗する

- 問題: `bun run check`のBiomeが、`config/persona.md`（T2-6でユーザーが書く人格プロンプト）に、見出しのあとの空行を足す整形を求めて失敗した
- 原因: Biomeの対象に`config/`のMarkdownが含まれていた。このファイルはLLMにそのまま送るプロンプトの本文で、ユーザーが書き換える
- 修正: `biome.json`の`files.includes`に`!config/persona.md`を足し、Biomeの対象から外した（本文は変えない）

## 261113035214 W2-2：待機中に戻ると、ログの末尾の返事の行が隠れる

- 問題: 返事が届いて待機中に戻ると、ログの最後の「>」の行が入力行の下に隠れ、「finished thinking in」の行までしか見えなかった（ヘッドレスのEdge、1280×432で確認）
- 原因: 返事を足したときに末尾へスクロールしたあと、入力行が再び出てログの高さが縮むのに、スクロールし直していなかった。実機では画面のキーボードの開閉でも同じことが起きる
- 修正: `apps/console/src/log_view.ts`で、ログの要素を`ResizeObserver`で見て、高さが変わったら末尾へスクロールするようにした
