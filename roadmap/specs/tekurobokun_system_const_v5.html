テクロボくん システム構成（展示版）

機体・入力端末・バックエンドPCの3台を、持ち込みのルーターで組んだLANだけでつなぐ。考える処理（llama.cpp）と声を作る処理（VOICEVOX）はすべてバックエンドPCに置き、機体は表示と再生だけを受け持つ。

会話1回の流れ

  1. 入力端末の有効な1台が、発言を utterance として送る。バックエンドは禁止語を検査し、全員に「考え中」を知らせる
  2. DialogueEngine が llama-server に人格プロンプトと履歴を送り、{say, emotion} を受け取って検証する。返事も禁止語を検査する
  3. TtsEngine が返事を文に分け、1文ずつ VOICEVOX で WAV にする
  4. 機体へ表情・字幕・WAVを文ごとに送り、入力端末へ返事と考えた時間を送る。状態は「話し中」
  5. 機体が最後の文の再生終了を返すと「待機中」に戻り、入力端末に次のプロンプトが出る

つなぎ方の決まりごと

  • 機器をまたぐ通信は、すべて apps/backend との WebSocket（ページの配信だけ HTTP）。機体と入力端末は直接つながらない
  • llama-server と VOICEVOX はバックエンドPCの中だけで呼ぶ。GPU は LLM、CPU は音声合成に分ける
  • モデルは OpenAI 互換の接続先として設定で差し替える。DialogueEngine の作りは変わらない
  • どの機器が落ちても自動で再接続する。切断中の機体は眠っている顔、入力端末は「つながっていません」
